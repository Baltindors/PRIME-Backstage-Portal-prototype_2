PRIME Backstage Portal - standalone prototype
=============================================

1. Unzip the whole folder first (don't open files from inside the zip preview).
2. Double-click index.html, then click "Start here", or jump to any screen.

- screens/   one self-contained page per artboard. Every page carries its own styles and
             rendering code, and they link to each other exactly like the canvas prototype.
- source/canvas.json   the canvas layout (pages, screen positions and titles)

Codes: activity code 123LV26 · staff code 4747 (AV Tech, Program Manager, leaving self check-in)

The prototype remembers the event mode, role and name you pick, so every screen
stays consistent as you click through. Use Chrome or Edge for the best results.
The Google Sans font loads from Google Fonts when you're online; offline the
screens fall back to your system font.

To host it as a website, upload the whole folder (index.html + screens/) to any
static host (SharePoint, Netlify, an S3 bucket, an intranet server).
